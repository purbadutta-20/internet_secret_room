{% if page_key == 'privacy' %}

This page explains the limited data used by this local browser game.

Information the game uses

  • Player identifier: the browser creates a random player ID and stores it in local storage so the game can associate your progress with the same browser.
  • Game progress: completed rooms, hints used, and a last-updated timestamp are stored in a local SQLite database on the server running this app.
  • Answers: the answer you submit is sent to the game server for checking. The current version does not need your real name, email address, or account password.
  • Server/hosting data: if hosted publicly, the hosting provider may process connection metadata such as IP address and request logs under its own terms. Confirm the provider's actual logging and retention settings before launch.

Purpose and retention

Data is used to operate the game and remember progress. Progress remains in the SQLite database until the operator deletes it or the database is removed. Use the in-game reset button to clear the current player's progress; this does not remove the browser's player ID or hosting logs.

Sharing and security

The current project has no analytics integration or user-account system configured. Do not add analytics, advertising, or external services without updating this notice. No internet service can guarantee absolute security; do not submit sensitive or confidential information to this game.

Children and contact

This is a fictional entertainment/student project, not a service intended to collect children's personal details. Before public deployment, the operator should add a monitored contact address and a process for privacy requests. No contact address has been configured in this demo, so none is invented here.

{% elif page_key == 'cookies' %}

The current version does not intentionally set browser cookies for advertising or analytics. It uses browser local storage, which is different from a cookie.

Browser storage

The key secretRoomPlayerId stores a random identifier in your browser so progress can be looked up on later visits from that browser. Clearing the site's local storage or browser data removes that identifier and may make previous progress inaccessible from this browser.

Server storage

The app stores room completion, hints used, and an update timestamp in SQLite. The reset button clears game progress for the current player but does not delete the local-storage identifier.

Third-party tools

The bundled version uses system fonts and does not embed third-party videos, social widgets, analytics, or ad scripts. Your hosting provider may still use essential infrastructure logs. Re-check this page if you add external scripts, fonts, embeds, or analytics.

Your choices

You can clear site data through your browser settings. If the site later adds non-essential cookies or tracking, update this policy and implement any consent mechanism required by applicable law before enabling them.
